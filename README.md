# lossless-image-rotator · 图片无损旋转器

一个用于**天文摄影 16-bit TIFF 图片无损旋转**的图形界面工具,在旋转图片的同时**完整保留 EXIF / XMP / ICC / IPTC 等全部元数据**。

## ✨ 功能特性

- 🖱️ 图形界面(GUI),操作直观,支持拖放添加文件
- 🔄 三种旋转方向:顺时针 90° / 逆时针 90° / 180°
- 📦 批量处理多个文件,或递归处理整个文件夹
- 🧬 **二进制级无损旋转** — 直接操作像素数据,不经过任何有损图像库
- 🏷️ **完整保留所有元数据**(EXIF、XMP、ICC、IPTC、Photoshop Resources)
- 💾 支持 16-bit 位深,专为天文摄影工作流(如 Siril)设计
- ⏹️ 后台线程处理,界面不卡顿,可随时停止

## 🚀 安装

需要 Python 3.8+ 和 numpy:

```bash
pip install -r requirements.txt
```

## 📖 使用方法

### 直接运行

```bash
python tiff_rotator.py
```

### Windows 双击启动(可选)

- `启动TIFF旋转工具.bat` — 双击启动(带控制台窗口)
- `启动TIFF旋转工具.vbs` — 双击启动(静默,无控制台窗口)

## 🖥️ 使用步骤

1. 点击「📂 添加文件」或「📁 添加文件夹」,也可以把文件直接拖进窗口
2. 选择旋转方向(顺时针 90° / 逆时针 90° / 180°)
3. 设置输出目录(默认在源文件夹下创建「旋转后」子文件夹)
4. 点击「▶ 开始处理」

## 🧩 依赖
